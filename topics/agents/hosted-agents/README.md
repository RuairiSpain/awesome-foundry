## Official Documentation

- [Build a voice agent with hosted agents](https://learn.microsoft.com/azure/foundry/agents/how-to/build-voice-agent) - Add real-time voice over WebSocket to a hosted agent.
- [Deploy a hosted agent](https://learn.microsoft.com/azure/foundry/agents/how-to/deploy-hosted-agent) - Deploy a hosted agent version from a container image with the CLI, SDK or REST.
- [Deploy a hosted agent from source code](https://learn.microsoft.com/azure/foundry/agents/how-to/deploy-hosted-agent-code) - Deploy a hosted agent by uploading source code instead of building a container.
- [Host Microsoft Agent Framework agents as Foundry hosted agents](https://learn.microsoft.com/azure/foundry/how-to/develop/framework-hosted-agents) - Package Agent Framework agents for Foundry hosting.
- [Hosted agent permissions reference](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agent-permissions) - Roles and permissions needed to build, deploy and invoke hosted agents.
- [Hosted agents in Foundry Agent Service](https://learn.microsoft.com/azure/foundry/agents/concepts/hosted-agents) - Concepts: containerized agents, sandboxed sessions, protocols and identity.
- [Manage hosted agents](https://learn.microsoft.com/azure/foundry/agents/how-to/manage-hosted-agent) - Promote, roll back and operate hosted agent versions.
- [Resilience for long-running Microsoft Foundry hosted agents (preview)](https://learn.microsoft.com/azure/foundry/agents/concepts/long-running-agent-resilience) - Patterns for checkpointing and resuming long-running hosted agents.
- [Run a hosted agent locally with the Azure Developer CLI](https://learn.microsoft.com/azure/foundry/agents/how-to/run-hosted-agent-locally) - Test a hosted agent on your machine before deploying.
