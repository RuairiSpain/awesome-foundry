## Official Documentation

- [Agentic Application Patterns](https://learn.microsoft.com/azure/durable-task/sdks/durable-agents-patterns) - Orchestration patterns for durable agentic applications.
- [Durable Agent Features](https://learn.microsoft.com/agent-framework/user-guide/agents/agent-types/durable-agent/features) - Feature reference for durable agents.
- [Durable Extension](https://learn.microsoft.com/agent-framework/hosting/azure-functions) - Host durable agents on Azure Functions with tutorials for single and multi-agent.
- [Durable Task Extension for Microsoft Agent Framework](https://learn.microsoft.com/azure/durable-task/sdks/durable-agents-microsoft-agent-framework) - Makes Agent Framework agents fault tolerant with durable sessions and checkpointing.
- [durable-agents docs](https://github.com/microsoft/agent-framework/tree/main/docs/features/durable-agents) - Feature documentation in the Agent Framework repository.
