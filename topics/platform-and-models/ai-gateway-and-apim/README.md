## Official Documentation

- [Bring Your Own Model to Foundry Agent Service](https://learn.microsoft.com/azure/foundry/agents/how-to/ai-gateway) - Route agent model traffic through an AI gateway.
- [Enable Semantic Caching for LLM APIs in Azure API Management](https://learn.microsoft.com/azure/api-management/azure-openai-enable-semantic-caching) - Configure semantic caching policies for LLM APIs.
- [Govern MCP Tools by Using an AI Gateway](https://learn.microsoft.com/azure/foundry/agents/how-to/tools/governance) - Apply API Management policies to MCP tools used by Foundry agents.
- [Import a Microsoft Foundry API](https://learn.microsoft.com/azure/api-management/azure-ai-foundry-api) - Import Foundry model endpoints into API Management with policies.
