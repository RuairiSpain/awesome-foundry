- [Install the Azure Developer CLI Foundry extensions](https://learn.microsoft.com/azure/foundry/agents/how-to/install-cli-foundry-extensions) - Install the azd extensions used for Foundry agents.
- [Microsoft Foundry agent extension overview](https://learn.microsoft.com/azure/developer/azure-developer-cli/extensions/azure-ai-foundry-extension) - Overview of the azd AI agent extension and its scaffold, provision and deploy flow.
