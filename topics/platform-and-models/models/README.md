## Official Documentation

- [Deploy Microsoft Foundry Models in the Foundry portal](https://learn.microsoft.com/azure/foundry/foundry-models/how-to/deploy-foundry-models) - Steps to pick a model from the catalog, set deployment options and name the deployment.
- [Foundry Models sold by Azure](https://learn.microsoft.com/azure/foundry/foundry-models/concepts/models-sold-directly-by-azure) - Reference list of models sold directly by Azure and their availability.
- [Microsoft Foundry Models overview](https://learn.microsoft.com/azure/foundry/concepts/foundry-models-overview) - Introduces the model catalog, model providers and how to choose between them.
- [Model router for Microsoft Foundry concepts](https://learn.microsoft.com/azure/foundry/openai/concepts/model-router) - Explains how model router sends each prompt to a suitable model and its routing modes.
- [Understanding deployment types in Microsoft Foundry Models](https://learn.microsoft.com/azure/foundry/foundry-models/concepts/deployment-types) - Compares Global, Data Zone, Provisioned and Batch deployment types for billing and data location.
- [What's new in model router in Microsoft Foundry Models](https://learn.microsoft.com/azure/foundry/foundry-models/whats-new-model-router) - Release notes for model router versions, supported models and regions.

## Guides & Tutorials

- [Compare models using the model leaderboard](https://learn.microsoft.com/azure/foundry/how-to/benchmark-model-in-catalog) - Use quality, safety, cost and throughput benchmarks to shortlist models.
- [Deploy open-source models with managed compute in Microsoft Foundry](https://learn.microsoft.com/azure/foundry/how-to/deploy-models-managed) - Deploy Hugging Face and other open models on managed compute with the SDK or REST.
- [How to use model router for Microsoft Foundry](https://learn.microsoft.com/azure/foundry/openai/how-to/model-router) - Deploy and call a model router deployment and choose a routing mode.
