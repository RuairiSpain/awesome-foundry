## Official Documentation

- [Connect agents to MCP server endpoints](https://learn.microsoft.com/azure/foundry/agents/how-to/tools/model-context-protocol) - Connect Foundry agents to public or private MCP servers with the MCP tool, project connections and tool-call approvals.
- [Explore Foundry MCP Server best practices and security guidance](https://learn.microsoft.com/azure/foundry/mcp/security-best-practices) - Security guidance for using the cloud-hosted Foundry MCP Server.
- [Get started using Foundry MCP Server with Visual Studio Code](https://learn.microsoft.com/azure/foundry/mcp/get-started) - Connect VS Code to the Foundry MCP Server at mcp.ai.azure.com and sign in with Entra.
- [Hosted MCP Tools](https://learn.microsoft.com/agent-framework/agents/tools/hosted-mcp-tools) - Declare MCP servers that the provider runtime calls for Microsoft Agent Framework agents.
- [MCP and Foundry Agents](https://learn.microsoft.com/agent-framework/user-guide/model-context-protocol/using-mcp-with-foundry-agents) - Use MCP tools with Foundry agents from Microsoft Agent Framework.
- [Set up authentication for MCP tools](https://learn.microsoft.com/azure/foundry/agents/how-to/mcp-authentication) - Choose between key-based, Entra managed identity, agent identity and OAuth identity passthrough for MCP servers.

## Samples & Code

- [Azure-Samples/app-service-mcp-foundry-agent-python](https://github.com/Azure-Samples/app-service-mcp-foundry-agent-python) - Chat web app on App Service that connects Foundry agents to remote MCP servers.
- [Azure-Samples/azmcp-foundry-aca-mi](https://github.com/Azure-Samples/azmcp-foundry-aca-mi) - azd template that self-hosts a remote Azure MCP server on Container Apps with managed identity for Foundry.
- [Azure-Samples/foundry-agent-service-remote-mcp-dotnet](https://github.com/Azure-Samples/foundry-agent-service-remote-mcp-dotnet) - Build a remote MCP server on Azure Functions in .NET and load its tools in Foundry Agent Service.
- [Azure-Samples/foundry-agent-service-remote-mcp-python](https://github.com/Azure-Samples/foundry-agent-service-remote-mcp-python) - Quickstart for a Python remote MCP server on Azure Functions used from Foundry Agent Service.
